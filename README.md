## 📌 Featured Projects

### 🌍 Explorezy 
– Full-Stack Travel Listing Platform Explorezy is a full-stack travel accommodation and destination listing platform inspired by Airbnb. It allows users to discover unique travel destinations, create and manage listings, upload images, and share travel experiences. The application includes secure user authentication and authorization, complete CRUD functionality, server-side validation, and a responsive UI for a smooth user experience across devices. Built using the MVC architecture, the project emphasizes clean code organization and efficient database management. 
**✨ Key Features** 
- 🔐 User Authentication & Authorization
- 🏡 Create, Edit & Delete Listings
- 📷 Image Upload Support
- 🗺️ Browse Destinations with Detailed Information
- 📱 Responsive User Interface 
-  ✅ Server-side Validation & Error Handling
   **🛠️ Tech Stack: Node.js, Express.js, MongoDB, Mongoose, EJS, Bootstrap, HTML, CSS, JavaScript ---

### 🧑‍🌾 Farmers Market 
– Online Agricultural Marketplace Farmers Market is a web-based marketplace designed to connect farmers directly with customers, reducing the gap between producers and consumers. The platform provides separate dashboards for farmers and users, allowing farmers to manage product listings while customers can browse available products, place orders, and track their purchases. The project focuses on creating a simple, user-friendly interface and an efficient product management system using a relational database. 
**✨ Key Features** 
- 💳 Secure Payment Gateway Integration
- 👨‍🌾 Separate Farmer & Customer Dashboards
- 🥬 Product Listing & Management
- 🛒 Order Placement & Tracking
- 🔍 Browse Products by Category
- 📦 Inventory Management
- 💾 Secure Database Connectivity
  **🛠️ Tech Stack:** Node.js, Express.js, MongoDB, Mongoose, EJS, Bootstrap, HTML, CSS, JavaScript ---
